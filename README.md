# PROJECT 2 – STUDENT PERFORMANCE TREND ANALYSIS

## About the Project
The Student Performance Trend Analysis project is designed to analyze a student's marks across multiple examinations and identify their academic performance trend. It calculates the average marks and determines whether the student's performance is improving, declining, or remaining stable.

## Technologies Used
- **Python** – Used to develop the program and analyze student marks.
- **Lists** – Used to store marks from multiple examinations.
- **Loops** – Used to process examination marks.
- **Conditional Statements** – Used to identify the performance trend.
- **Arithmetic Operations** – Used to calculate average marks.

## Main Features
- Accepts marks from multiple examinations.
- Stores examination marks in a list.
- Calculates the average marks.
- Compares marks between examinations.
- Identifies whether performance is improving, declining, or stable.
- Displays the student's performance report.

## Algorithm
1. Start the program.
2. Get the number of examinations.
3. Enter the marks obtained in each examination.
4. Store the marks in a list.
5. Calculate the average marks.
6. Compare the marks of consecutive examinations.
7. Identify the performance trend.
8. Display the average marks and performance trend.
9. Stop the program.

## Sample Output
```text
Enter number of examinations: 3

Enter marks for Exam 1: 60
Enter marks for Exam 2: 70
Enter marks for Exam 3: 85

----- STUDENT PERFORMANCE REPORT -----

Marks: [60, 70, 85]
Average Marks: 71.67
Performance Trend: Improving
```

## Conclusion
This project helps analyze students' academic performance across multiple examinations. It identifies performance trends and calculates average marks using Python concepts such as lists, loops, conditional statements, and arithmetic operations.
